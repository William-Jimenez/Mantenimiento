# ECC Continuous Learning - Repositorio de Instintos del Proyecto

Este directorio contiene los aprendizajes y patrones consolidados del proyecto descubiertos durante las sesiones de trabajo con agentes autónomos.

## Estructura
- Los instintos atómicos registran lecciones sobre:
  - Manejo de políticas de ejecución de scripts en Windows (`powershell -ExecutionPolicy Bypass` y `npm.cmd`).
  - Compatibilidad de sintaxis en PowerShell 5.1 (evitar operadores no soportados y emojis que alteren la codificación).
  - Flujo riguroso de 3 ramas (`dev` -> `qa` -> `main`).
  - Restricciones visuales del modelado 3D (sin botones ni opciones de zoom, render responsivo sin recortes).
